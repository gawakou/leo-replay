# v0.2.0 implementation note

## Objective

v0.1.0の実測時系列再生基盤を壊さず、既存のイベント抽出・補正コードを正式な実験機能として統合する。

## Implemented

1. Event Profile v1とJSON Schema
2. 旧形式との双方向変換
3. `leo-replay profile generate --mode event`
4. `leo-replay replay --mode event`
5. 短時間イベントのスケジューリング
6. `tc`適用時刻と遅延のJSONL記録
7. イベント開始、継続時間、RTTピーク、MAE/RMSE評価
8. v1対応の遅延・ジッタ・スパイク補正
9. 既存時系列モードの回帰維持

## Research continuity

本実装は、研究報告で示した次の課題に直接対応する。

- 0.5秒時系列では短時間スパイクを十分再現できない
- 時系列再生とイベント単位再生の比較が必要
- 同一条件で複数回再生し、安定性を評価する必要がある

v0.2.0はTLEやルーティングを直接追加せず、実測データ駆動型再現という研究軸の中で、通信低下イベントの再現精度を評価可能にする段階である。

## Remaining validation

- Ubuntu検証ルータにおけるroot権限での実`tc`適用
- 50～500 msイベントの適用遅延分布
- 同一イベントプロファイルの反復再生分散
- 時系列方式とイベント方式の同一データ比較
- UDP送信条件別の再現性
