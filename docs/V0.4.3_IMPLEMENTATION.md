# v0.4.3 Implementation Notes

## Scope

v0.4.3 provides a synchronized 2D geographic map and communication timeline for outputs produced by v0.4.2. It is intentionally an explanatory layer and does not change replay profiles or infer the actual serving satellite.

## Components

- `leo_replay.visualization.bundle`: normalization and self-contained HTML bundle generation.
- `leo_replay.visualization.server`: loopback-by-default static server.
- `leo_replay.visualization.assets`: offline HTML, JavaScript, CSS, and simplified land outline.
- `visualization-bundle-v1.schema.json`: machine-readable output contract.
- `leo-replay viz build`: creates the bundle.
- `leo-replay viz serve`: serves a built bundle.

## Synchronization

The v0.4.2 selection observation timestamps define the visualization frames. Relative communication profiles and Event Profile v1 are aligned to `--profile-start-utc`, or to the first selection timestamp by default. Communication states are sampled as piecewise-constant values at each frame. Visibility rows use nearest-time matching with a configurable tolerance.

## Security and reproducibility

- The generated HTML contains no external JavaScript, CSS, fonts, tiles, or telemetry.
- `viz serve` binds to loopback by default and refuses non-loopback binds without explicit opt-in.
- Every input is recorded with SHA-256 and byte size in `data.json`.
- Output files are hashed in `manifest.json`.
- The generated map preserves causal/retrospective semantics and includes a serving-satellite disclaimer.

## Known limits

- Equirectangular projection distorts high latitudes.
- Paths crossing the antimeridian are not split and can draw across the map.
- Browser rendering of many thousands of satellites and frames can be expensive.
- Position delta is a sensitivity indicator, not a covariance-derived uncertainty bound.
- The first version does not include 3D globe rendering, ground-gateway inference, or live measurements.
