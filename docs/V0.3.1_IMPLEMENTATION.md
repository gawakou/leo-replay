# v0.3.1 implementation summary

## Added components

- `labs/docker-bidirectional/`: three-container virtual inline router
- `labs/netns-bidirectional/`: three-namespace veth testbed
- `src/leo_replay/lab_metrics.py`: ping, iperf3 and execution-log validation
- `docs/VIRTUAL_TESTBED.md`: scope, commands and limitations
- `.github/workflows/docker-lab.yml`: Docker fixed/profile smoke tests

## Acceptance criteria

- Docker Compose does not require `--privileged`.
- Router receives only `NET_ADMIN` and namespaced forwarding sysctls.
- Client and Server use explicit routes through the Router.
- Fixed forward/reverse delay and rate conditions are distinguishable.
- Directional profile replay records both directions.
- Cleanup scripts remove qdiscs and virtual topology.
- Unit and repository tests pass without requiring Docker or root.

## Validation boundary

The release package was validated with Python tests and shell syntax checks. Actual Docker Engine and network-namespace execution must be completed on the target macOS/Ubuntu environments because the packaging environment does not provide Docker and does not permit creation of network namespaces.
